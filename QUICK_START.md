# QUICK START GUIDE

## ⚡ 5-Minute Setup

### Step 1: Install Dependencies (1 minute)
```bash
pip install -r requirements.txt
```

### Step 2: Run Pipeline (30 seconds)
```bash
python run_pipeline.py
```

This will:
- ✅ Generate 2,500+ mock sales transactions
- ✅ Create realistic inventory, customer feedback, and operations data
- ✅ Run AI anomaly detection
- ✅ Perform data quality validation
- ✅ Generate executive reports
- ✅ Create 30-day revenue forecasts

### Step 3: Launch Dashboard (10 seconds)
```bash
streamlit run dashboard.py
```

Opens at: **http://localhost:8501**

## ⚙️ Troubleshooting

### Issue: Dashboard won't load
**Solution**: 
```bash
pip install --upgrade streamlit
streamlit run dashboard.py
```

### Issue: No data showing
**Solution**:
```bash
python run_pipeline.py
# Wait for completion, then restart dashboard
```

### Issue: Import errors
**Solution**:
```bash
pip install -r requirements.txt --force-reinstall
```
